# Snake Game

基于 Pygame Zero 的贪吃蛇游戏。

## 安装

1. 创建并激活虚拟环境：
```bash
python -m venv venv
.\venv\Scripts\Activate.ps1  # Windows
```

2. 安装依赖：
```bash
pip install pgzero
```

## 运行

```bash
python snake.py
```

## 操作

- 方向键 ↑ ↓ ← → 控制蛇的移动
- 吃到红色食物得分
- 撞墙或撞到自身游戏结束

## 技术栈

- Python 3.11
- Pygame Zero
- Pygame
